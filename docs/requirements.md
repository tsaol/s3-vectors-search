# S3 对象语义检索：需求 v0.1

2026-11-24。本文是需求原文；每一条在本 repo 里怎么实现，见 [architecture.md](architecture.md#需求对照)。

## 1. 需求来源

S3 桶里存放着大量非结构化对象，包括文档、图片和视频，现在只能按对象名称查找。需要按内容做语义检索：用自然语言描述要找的内容，返回相关的对象和片段。向量要能放进统一的向量库，和其他数据源使用同一套 embedding 规则。

## 2. 现状

对象存放在一个 AWS 区域的 S3 桶中，规模为百 TB 级。对象类型以文档和图片为主，另有一部分视频。对象由业务系统通过分片上传写入，同一对象会被新版本覆盖。对象的访问权限由业务系统管理，S3 上只有对象本身。

## 3. 目标

- **一致**：所有对象按统一的抽取、切分和 embedding 规则生成向量，和其他数据源可以放在一起检索。
- **就近**：对象在所在区域内处理，离开区域的只有向量和元数据。
- **同步**：新增、覆盖、删除都能反映到向量库，存量对象可以一次性回填。
- **受控**：检索结果只包含调用方有权访问的对象。

## 4. 范围

- 范围内：一个 S3 数据源，对象类型为文档、图片、视频；从对象写入 S3 开始，到向量和元数据写入指定向量库，以及按权限检索。
- 范围外：向量库的选型和建设、检索结果排序、检索界面、其他数据源的接入。

## 5. 功能需求

| 编号 | 需求 | 说明 | 优先级 |
|---|---|---|---|
| FR-1 | 增量触发 | 对象写入完成后自动进入处理；失败可重试；重复触发不产生重复向量 | P0 |
| FR-2 | 删除和覆盖同步 | 对象删除或被新版本覆盖时，删除或更新对应的向量；非业务操作导致的删除（如自动过期）通过定期对账补齐 | P0 |
| FR-3 | 存量回填 | 对已有对象批量处理，可按前缀、时间分批，可暂停和续跑 | P0 |
| FR-4 | 文档抽取 | 文档抽取正文；扫描件做文字识别，支持中文；无法解析的对象记录原因，不阻塞其他对象 | P0 |
| FR-5 | 图片理解 | 图片可以按画面内容和图中文字检索，支持以文搜图 | P0 |
| FR-6 | 视频理解 | 视频可以按画面内容和语音内容检索，结果定位到时间段；抽帧按画面变化进行，避免对静止画面重复处理 | P1 |
| FR-7 | 切分 | 文档按统一规则切分（长度、重叠、按标题或段落）；视频按时间段切分；规则可配置 | P0 |
| FR-8 | embedding | 使用指定的模型和维度；文本、图片、视频的向量能否放在同一检索空间，按所选模型确定；模型更换时支持全量重算 | P0 |
| FR-9 | 元数据 | 每个向量附带对象路径、版本、对象类型、所属部门、上传人、时间、切片序号或时间段、访问权限字段 | P0 |
| FR-10 | 写入向量库 | 按指定向量库接口批量写入；失败可重试；对象数、切片数、向量数可对账 | P0 |
| FR-11 | 权限过滤 | 检索时按调用方权限过滤，只返回有权访问的对象；依赖 FR-9 的权限字段 | P0 |
| FR-12 | 问答 | 在检索结果基础上回答问题并标注来源对象；检索不到时明确说明，不编造 | P1 |
| FR-13 | 运行监控 | 处理积压、失败数、处理延迟、每日处理量可见，异常告警 | P1 |

P0 为第一期必须具备，P1 为第一期之后补齐。

## 6. 非功能需求

- **NFR-1 数据驻留和合规**：对象不离开所在区域。向量和元数据可能包含个人信息，存放位置以及能否跨区域，由安全和合规团队确认。
- **NFR-2 安全**：处理过程只读源桶，按最小权限授权；处理组件不暴露到公网；传输和存储加密；不保留对象副本。
- **NFR-3 成本**：避免下载对象产生的传输费；视频处理按画面变化抽帧控制计算量；日常增量成本和存量回填成本分别估算。
- **NFR-4 时效**：新对象从写入到可检索的延迟目标待确认（分钟级或小时级）。
- **NFR-5 规模**：支撑百 TB 级存量回填，同时不影响日常增量处理。
- **NFR-6 一致性**：模型和切分规则有版本号，向量记录所用版本，便于全量重算。
- **NFR-7 可替换**：抽取、切分、模型、向量库各环节可以单独替换。

## 7. 待确认的问题

1. 向量库用什么产品，部署在哪里？向量和元数据能否跨区域？
2. embedding 模型是否已定？文本、图片、视频是否要求在同一检索空间？
3. 文档抽取、文字识别、切分是否有统一规则？
4. 检索是否按调用方权限过滤？权限数据从哪里获取（接口、导出、同步频率）？
5. 第一期范围：全量回填，还是只做增量加指定前缀？
6. 视频的占比和平均时长？是否需要语音内容检索？
7. 新对象从写入到可检索的延迟要求？
